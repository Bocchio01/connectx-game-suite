Detailed Description

Level 6: the policy network plays alone, with no search at all.

The position is encoded as two planes (my stones / the opponent's stones), the network produces one score per column, illegal columns are masked out and the best one is played. A move costs a single forward pass (microseconds): this is also exactly what the Arduino sketch does with the TensorFlow Lite version of the model.

Optional extras:

  • temperature > 0 samples the move from softmax(score / temperature) instead of taking the best;
  • mirror averages the answer with the one for the left-right mirrored board (Connect-X is symmetric, so both must agree: the average cancels some noise);
  • tactics plays an immediate win / blocks an immediate loss without asking the network.
