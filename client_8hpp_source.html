107 // ===========================================================================
108 // Synchronous Requests
109 // ===========================================================================
110 //
111 // Each one sends the request and blocks until the server has answered. They need the event loop
112 // (run()) to be running in another thread, which is the one that receives the answer: calling them
113 // from a callback would block that very thread, so it is refused. Only one request is in flight at a
114 // time (the answers do not say which request they belong to); the others wait their turn.
115 //
116 // The result is std::nullopt if the answer does not arrive in `timeout_ms` or the connection is lost.
117 // If the server refuses the request with an ERROR message the call returns at once with
118 // success == false and the server's explanation in `message` (for requestGamesList(), which has
119 // neither, with std::nullopt); the error is also reported to the onError() callback, first.
120 std::optional<ConnectResponse> requestConnect(const std::string &player_name, int timeout_ms = 3000);
