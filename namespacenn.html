Softmax of one row of logits: p_j = exp(l_j - max) / sum_k exp(l_k - max). Subtracting the maximum does not change the result and prevents overflows.

Parameters

◆ softmaxCrossEntropy()

Real nn::softmaxCrossEntropy ( const Matrix & logits,
const Matrix & targets,
Matrix & dlogits,
const Matrix * mask = nullptr )

Cross-entropy between the softmax of the logits and a target distribution: 

loss_i = - sum_j target_ij * log( softmax(logits_i)_j )

It is the loss of the policy: the network is pushed to put its probability mass where the target (a solver's verdict, or the visit counts of a tree search) puts it.

The gradient of the softmax + cross-entropy pair is the famously simple dLoss/dLogit_j = softmax_j * sum(target) - target_j (= p_j - t_j for a proper distribution).

Parameters
maskoptional (batch x classes) matrix: classes whose entry is 0 are excluded from the softmax and get no gradient (illegal moves)
dlogitsreceives the gradient of the mean loss over the batch
Returns
the mean loss over the batch
