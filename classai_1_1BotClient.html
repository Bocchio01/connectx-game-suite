Detailed Description

A computer player: connects to a server through the same Client class used by the CLI and the GUI, joins (or creates) a game and plays it with an Agent until the game is over.

Only two-player games on boards that the bitboard engine supports can be played (see Geometry::isSupported); anything else is refused with an explanatory message.
