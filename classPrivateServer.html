Detailed Description

A server of our own for offline games: connectx-server run as a child process on a free port of this computer (--bind 127.0.0.1: nobody else can reach it), which lives as long as the offline session and never longer.

start() asks the operating system for a free port, starts the program and waits until the port accepts connections (the program announces itself on its output, and the port is probed anyway); ready() or failed() follow. Not a place for UI: the window decides what to tell the user.
