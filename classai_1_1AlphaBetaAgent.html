Detailed Description

Level 3: negamax with alpha-beta pruning.

Same minimax value as MinimaxAgent (the tests check it) but it visits a tiny fraction of the nodes thanks to

  • alpha-beta pruning,
  • move ordering (centre columns first, then the best move found so far),
  • tactical shortcuts: an immediate win ends the search of a node and moves that let the opponent win at once are never searched.

Optional "engine" features, enabled with time_limit_ms or iterative:

  • iterative deepening: depth 1, 2, 3 ... until the depth or the time limit is reached, always keeping the answer of the last completed depth; the previous iteration provides the move ordering;
  • a transposition table caching the result of already searched positions (the same position is reached by many move orders).
