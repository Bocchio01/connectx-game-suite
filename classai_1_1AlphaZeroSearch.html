Detailed Description

Monte Carlo tree search guided by a policy/value network (AlphaZero style).

It is MCTS (see MctsAgent) with two changes that make the search both much more selective and much cheaper than random rollouts:

  • instead of simulating a game to the end, a new leaf is evaluated by the network's value head (who is winning?);
  • instead of treating all moves alike, the policy head gives every move a prior probability P and the selection rule (PUCT) favours moves that are both promising on average (Q) and that the network likes but have not been explored yet: 
    score(move) = Q(move) + c_puct * P(move) * sqrt(N_parent) / (1 + N(move))

The visit counts at the root are an improved policy: better than the raw network output. In self-play they are the target the network is trained towards (the policy-improvement step), and the game result is the target for the value (policy evaluation).
