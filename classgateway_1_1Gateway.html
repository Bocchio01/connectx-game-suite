Detailed Description

Lets browsers play on a game server.

A browser cannot open a TCP connection, which is what the clients of the server (the CLI, the GUI, the computer players) do: all it can do is to open a WebSocket. The gateway is the adapter: it listens for WebSockets and gives each browser a TCP connection of its own to the game server, carrying the messages from one to the other. The server needs to know nothing about it, and it holds no game: whatever is in a game lives in the server.

It is meant to sit behind a reverse proxy (nginx, for instance) that takes care of TLS, which is mandatory for a page served over https. See the README of this module.
