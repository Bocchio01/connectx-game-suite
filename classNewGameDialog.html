Detailed Description

Dialog to configure a new game: optional name, board size, number of players, connect length and the opponent: other people (who join from the lobby) or the computer, with a strength level.

The ranges are the ones accepted by the server (the connect length is limited by the board). The computer can be chosen only when the helper program was found and plays this kind of game (two players, a board that fits its engine): otherwise its button is disabled, with a tooltip that says why. The last values are remembered with QSettings.
