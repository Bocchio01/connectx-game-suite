◆ NN_REAL_TYPE

#define NN_REAL_TYPE   float

Scalar type used by the whole library. It is float (what TensorFlow Lite uses too); the gradient-checking test rebuilds the library with -DNN_REAL_TYPE=double to compare analytic and numerical gradients without float rounding noise.
