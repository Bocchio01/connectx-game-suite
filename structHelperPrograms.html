Detailed Description

Where the helper programs of the suite are: connectx-ai (the computer player) and connectx-server (a private server for offline games). They are separate programs that the GUI runs as child processes, exactly as a user would from a terminal: the GUI does not link the AI library. Both are optional; what needs a missing helper is disabled, with a tooltip that says so.
