Detailed Description

A two-headed multilayer perceptron in the style of AlphaZero: 

                     +--> Dense(policy_size) ----------------> policy logits

input --> trunk ----—+ (Dense + ReLU)* +--> Dense(1) --> tanh -----------------> value in (-1, 1)

The trunk is shared: its features are used both to say which move looks best (policy) and who is winning (value). Training both tasks at once makes the features richer than training each task alone.

Only standard operations are used (fully connected + ReLU + tanh), so the very same network can be rebuilt in Keras and converted to TensorFlow Lite.
