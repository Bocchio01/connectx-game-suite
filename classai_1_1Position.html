Detailed Description

A game position for two players, optimised for tree search.

The position is stored relative to the player to move: current() always holds the stones of the side that has to play and opponent() the others. After play() the roles swap with a single XOR, so no side-to-move flag and no player ids are needed. The whole object is 4 machine words and is trivially copyable, which makes "copy, play, recurse" search cheap (no undo logic needed).

This is the engine used by every AI agent. The network/GUI layers keep using the reference implementation in core; the unit tests check that both implement exactly the same rules.
