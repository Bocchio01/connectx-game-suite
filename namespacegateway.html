Writes all the data. Unlike a plain write, it does not raise SIGPIPE when the other side has already hung up (that would kill the whole process): it just fails.

◆ waitForData()

bool gateway::waitForData ( const sockpp::socket & socket,
int timeout_ms )

Waits until there is something to read on the socket (or somebody hung up), for up to timeout_ms. Readers wait in short slices instead of blocking in read(), so that they can notice when another thread wants them to stop: closing a socket under the feet of a reader is not safe, nor does it wake it up on every platform.

Returns
true if a read will not block (it may report an error or the end of the stream)
