Detailed Description

The doorman of one browser. It stands between the browser and its connection to the game server and makes sure that the visitor can only do what a visitor should be able to do:

  • the session token never reaches the browser: the gatekeeper keeps it and puts it in the requests;
  • names and board shapes are checked before the server sees them;
  • a connection takes part in one game only, and whoever creates a game joins it at once (the server forgets a game when its last player leaves, but a game that nobody ever joined would stay for ever);
  • what a browser may send is a short list, nothing else gets through.

It knows nothing about sockets: it turns strings into strings, which makes it easy to test.
