Detailed Description

Helpers to run (and take pictures of) widgets on the "offscreen" Qt platform, which has no desktop to take the fonts and the settings from.

◆ useIsolatedSettings()

void OffscreenSupport::useIsolatedSettings ( const QString & directory)
inline

Keeps the QSettings of the test away from the real ones (other organisation name). On Windows the native store (the registry) is used: the .ini files of QSettings occasionally take seconds to be written there (file locking, virus scanners), which makes the timing of the tests unpredictable. Elsewhere an .ini file in directory is used. Each test program gets a key of its own (the process id is part of the name): programs that run at the same time (ctest -j, two sessions on one machine) must not read each other's settings. Call after creating the application, and removeIsolatedSettings() before the program ends.
