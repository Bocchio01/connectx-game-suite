Detailed Description

Level 4: perfect play. Uses the exact Solver to score every move and plays the best one (the fastest win, or the slowest defeat).

Solving early positions of a 6x7 board can take minutes, so a time limit can be set: when the exact search does not finish in time the agent falls back to an iterative-deepening alpha-beta search. The transposition table is kept between moves and games (a position solved once stays solved).
