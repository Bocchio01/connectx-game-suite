Detailed Description

Main window: a stack of three pages (Connect -> Lobby -> Game), a menu bar and a status bar.

The window owns the NetworkController and is the only place that connects the pages to it: the pages never know about the network, the controller never knows about the pages.

It also runs the two helper programs of the offline features, as child processes that never outlive their use: the computer opponent of a game (ComputerPlayer, started once the game exists) and the private server of an offline session (PrivateServer, stopped when the session ends).
