Detailed Description

The computer opponent: the connectx-ai helper run as a child process, which connects to the server like any other client, joins a game that already exists and plays it. Nothing here knows about widgets or about the network protocol: the owner builds the Options and reacts to the signals; the game itself is watched through the normal game states coming from the server.

It never outlives its use: stop() ends it, destroying the object ends it at once, and the program is killed if it ignores the request to end.
