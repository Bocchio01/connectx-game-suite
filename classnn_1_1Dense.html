Detailed Description

Fully connected layer: y = x W + b, with W of shape (inputs x outputs). (Keras' Dense uses the very same layout for its kernel, which makes the export to TensorFlow a plain copy.)

Backward pass, with dY = dLoss/dY and a batch of N samples: dW = X^T dY (sum over the batch of the outer products x_n dy_n) db = sum_n dy_n dX = dY W^T
