Detailed Description

The strength levels of the computer opponent, and what each one means for the connectx-ai helper (run connectx-ai --list-agents for the agent specs). The table is in computer_levels.cpp, in one place, so that it can be tuned without touching anything else.

Pure logic, no widgets and no process handling: the GUI only builds a command line from it.
