Detailed Description

Custom painted game board for any size (4..20 x 4..20) and up to 4 players.

The board scales with the widget keeping its aspect ratio. Discs sit behind the board face, so that the holes really are holes and falling discs slide behind the frame. Features: hover/keyboard "ghost" disc, drop animation of the newly appeared discs only, last move marker, winning line highlight and a banner overlay (waiting / result).

The widget never talks to the network: it emits columnActivated() and the owner decides.
