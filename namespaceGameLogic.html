Detailed Description

Pure game helpers used by the GUI: no Qt, no network, easy to unit-test.

Boards follow the wire convention of the protocol: board[0] is the TOP row, a cell holds 0 when empty and the player id (1..N) otherwise. A disc dropped in a column lands in the lowest empty row of that column.

◆ findWinningLines()

std::vector< std::vector< Cell > > GameLogic::findWinningLines ( const BoardBoard & board,
uint8_t player,
int connectLength )

Finds every run of at least connectLength consecutive discs of player along a row, a column or one of the two diagonals. Each run is returned as the ordered list of its cells (left to right, or top to bottom for columns) and includes ALL of the consecutive discs, even when the run is longer than connectLength. Empty when the player has no such run.
