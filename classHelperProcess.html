Detailed Description

A helper program run by the GUI as a child process (the computer player, the private server).

What every helper needs, once: its output (stdout and stderr merged, the last lines are kept to explain a failure), no console window on Windows, and above all a guarantee that it never outlives its use: stop() asks it to end (and kills it after kGracePeriodMs), the destructor stops it synchronously, and on Windows the operating system itself kills it if the GUI dies without cleaning up.

Not a place for decisions: the owners (ComputerPlayer, PrivateServer) decide what an exit means.
