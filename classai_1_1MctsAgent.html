Detailed Description

Level 5: Monte Carlo Tree Search with UCT (Kocsis & Szepesvari).

No evaluation function and no game knowledge beyond the rules: the value of a move is estimated by playing many games to the end. Every simulation has four steps:

  1. selection walk down the tree choosing the child with the best UCT score (average result + an exploration bonus for rarely visited moves);
  2. expansion when a leaf that was already visited is reached, create its children;
  3. simulation play the game to the end from the new node with a cheap rollout policy;
  4. backprop add the result to every node of the path. After the simulations the most visited move at the root is played.

Two rollout policies are available: purely random moves (the textbook version) or "tactical" moves (take an immediate win, avoid moves that lose at once), which makes every simulation far more informative.
