Detailed Description

Turns the bytes received from a browser into events, one after the other.

It checks everything a server has to check: the frames must be masked, there are no extensions (so no reserved bits), the control frames are short and whole, a message that is split into several frames is put back together, it is not longer than the limit and it is valid UTF-8. After a Close frame or a failure it produces nothing more.
